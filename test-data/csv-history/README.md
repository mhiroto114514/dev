# 全7回の成績一覧：手動テスト用CSV

元データ: `C:/Users/user/Downloads/gakute3_1.csv`（26人、第1回）。
氏名は「テスト生徒01〜26」、生徒コードは `9900001〜9900026` に置換しています。
得点・偏差値は元データを基にしているため、完全な架空データではありません。
元CSV自体は変更していません。ファイルはUTF-8 BOM付き、元CSVの20列に fourth_choice / fifth_choice を追加した22列です。
第4・第5志望は学校ID1〜5から、既存の志望校と重複しない2校を順に選んでいます。対象DBにこれらの学校IDが必要です。

## 正常系の5回分

`normal-five-rounds/` の gakute3_1.csv 〜 gakute3_5.csv をまとめて選択してください。
各25人分で、元の氏名・生徒コードを使用しています。第1回は元CSVのコピーに第4・第5志望を追加したもの、第2〜5回は成績を加工したテストデータです。
5校の表示・判定・印刷を確認できます。Downloads内の元ファイルは変更していません。

## 使い方

「全7回の成績一覧」タブで、下表の組み合わせをケースごとに選択してください。
フォルダ内のCSVを全部まとめて選ばないでください。意図的に不正なCSVを含みます。
新規選択時は前の選択を置き換えます。

このセットは保存しない一覧機能向けです。「今回の成績・判定」で取り込むとテスト用生徒・成績がDBに保存されるため、既存機能との比較はテスト用DBで行ってください。
第1〜第3志望の学校IDは元CSVの値です。対象DBにも同じ学校マスタが必要です。

## 印刷・画面の確認

- ケース1をA4横向きで印刷プレビューし、全26人が最後まで出力されること。
- 氏名・見出し・第1〜7回の表がページ境界で分断されないこと。
- 学校名が長い場合にも折り返され、判定が隠れないこと。
- タブ・ファイル選択・ボタンが紙に出ず、選択した帳票だけが印刷されること。
- タブを往復しても選択済みファイルと結果が保たれ、勝手に再取込されないこと。
- エラーのケースでは不完全な帳票や、直前の成功結果を今回の結果として表示しないこと。

## DB保存なしの確認

テスト前後で student / result の件数だけでなく既存の行内容も比較してください。
正常ケースの再実行、重複ケース、エラーケースのいずれでも変更がないことが合格です。
件数だけでは既存行の更新を検出できません。DB初期化・削除は必要ありません。
